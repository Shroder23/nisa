## Content rule

Only structural labels and ordinary empty-state copy. Blank media slots and neutral bars where private or dynamic data belongs. Empty form values. No fake member identities, human imagery, sample chats, precise locations, counts, badges or statistics. In preview output, placeholders communicate layout only; real Flutter screens must use genuine data or honest empty states.

Also produce an enlarged-text/narrow-screen adaptation and RTL adaptation for this screen where applicable. Use reviewed translations if supplied; otherwise keep an RTL layout study with neutral text bars and do not invent Urdu/Punjabi wording. Save variants with descriptive suffixes such as `_empty`, `_error`, `_large_text` or `_rtl`.

## Finish

Match the shared palette, typography, radii, icon weight and spacing. Preserve the actual workflow. Check for overlap, clipped controls, false statuses and accidental invented data. If the recipe refers to unsupported functionality, omit that control and report the omission to the coding agent rather than inventing it.
