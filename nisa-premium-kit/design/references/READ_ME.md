# Concept reference notes

Use the Home portrait as the clearest composition reference. The two overview boards illustrate twelve screen families; they are not full-size screen exports. Individual per-screen Nano Banana prompts are supplied for exact workflow references.

Image-generation details must not override implementation requirements: the welcome screen must omit authenticated menu/bell controls; use the official Google brand asset rather than the generated letter; do not ship the generated document-security claim without policy review; use a neutral document icon before verification, not a verified checkmark. Nested routes should follow the existing navigation structure rather than inheriting the root bar blindly.

The supplied Flutter code uses flat colors and the app's existing fonts. Bundle approved fonts/brand assets separately when available. Do not crop letters, UI controls or profile placeholders out of these images for production.
